# 🐍 Python Programming MOOC 2026 — Solutions

Solutions for the **[Python Programming MOOC 2026](https://programming-26.mooc.fi/)** course by the University of Helsinki.

---

## 🛠 Tools & Environment

* **Language:** Python 3.x
* **IDE:** VS Code (TMC Plugin)
* **VCS:** Git / GitHub
* **Libraries:** Pygame

---

## 🚀 What I Learned Throughout the Courses

* **Python Fundamentals:** Variables, basic data types, conditional statements (`if-elif-else`), and loops (`for`, `while`).
* **Functions & Scope:** Defining custom functions, passing parameters, handling return values, and managing scope.
* **Data Structures:** Working with lists, dictionaries, tuples, and sets to organize and process data efficiently.
* **File Handling:** Reading from and writing to files (text, CSV, etc.), parsing data, and managing data persistence.
* **Object-Oriented Programming (OOP):** Creating and working with classes and objects, defining methods, constructors, and encapsulation.
* **Functional Programming Concepts:** Utilizing list comprehensions, lambda expressions, and working with higher-order functions.
* **Game Development with Pygame:** Building graphical 2D games, handling user input (keyboard/mouse events), managing game loops, rendering graphics, tracking scores, and managing game states.
* **Algorithmic Thinking & Problem Solving:** Breaking down complex problems, handling exceptions, writing clean code, and utilizing automated testing via the TMC plugin.
* **Version Control:** Managing code changes using Git and showcasing completed projects on GitHub.
